# My Little Tasks

A native macOS menu bar app for quick task tracking and note taking.

## Downloads

- [macOS app bundle](MyLittleTasks-macOS.zip) — unzip and move `MyLittleTasks.app` to Applications.
- [App source](MyLittleTasks-source.zip) — Swift package source and app icon assets.

The source targets macOS 14 or later. To build from source, run `swift run TaskNotesBarApp` from the extracted source folder.
